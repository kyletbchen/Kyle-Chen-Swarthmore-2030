Personal Project

Halloween Hand Launcher

Mechanical Design 3D Modeling Embedded C Sensors

Overview

Every year my family puts together an elaborate Halloween display, and this was my engineering contribution: an automated launcher that fires a skeleton hand into the air to startle trick-or-treaters. After researching ways to launch a lightweight prop safely and repeatably, I designed and 3D-modeled the housing and fabricated a linear track mechanism that uses a set of heavy elastic bands to catapult the hand upward.

I wrote the control code that uses a proximity sensor to detect when someone walks up and automatically trigger the launch, along with a return-reset feature that pulls the mechanism back and reloads it automatically so it's ready for the next visitor without anyone resetting it by hand. The whole mechanism is hidden inside a disguised bucket enclosure, with added aesthetic elements to keep the prop concealed until it fires.

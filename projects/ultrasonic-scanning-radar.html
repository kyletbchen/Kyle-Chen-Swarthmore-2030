Personal Project

Ultrasonic Scanning Radar

Embedded C Ultrasonic Sensing Signal Processing Motor Control

Overview

This project started as an exploration of how rotating LIDAR units map their surroundings, built instead around a cheap ultrasonic sensor. An HC-SR04 ultrasonic rangefinder is mounted on a micro-servo that continuously sweeps it back and forth across a 180° field of view, taking a distance reading at each angle as it goes.

Those angle-distance pairs are streamed to a laptop in real time, where a Processing/Python dashboard converts each reading into polar coordinates and plots it, building up a live map of nearby objects as the sensor sweeps — the same basic idea behind rotating LIDAR units used in robotics, just built around a much cheaper sensor. Tuning the sensor timing and filtering out noisy readings got the system to ±1 cm detection accuracy.
